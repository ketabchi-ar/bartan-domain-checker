# 🌐 گزارش و ابزار استعلام دامنه‌های برند bartan (ایران‌سرور)
### Bartan Domain Checker & TLD Pricing Report

این پروژه وضعیت در دسترس بودن (ثبت‌شده یا آزاد بودن) نام دامنه **bartan** را به همراه قیمت‌های رسمی به تومان در میان تمامی **۴۳۹ پسوند (TLD)** ارائه‌شده در وب‌سایت **ایران‌سرور (IranServer)** بررسی و تحلیل می‌کند.

---

## 📊 نتایج کلیدی (Summary)
* **تعداد کل پسوندهای بررسی‌شده:** ۴۳۹ پسوند
* **تعداد دامنه‌های آزاد و قابل ثبت:** ۴۳۰ پسوند
* **تعداد دامنه‌های ثبت‌شده (اشغال):** ۹ پسوند (`.com`, `.net`, `.org`, `.ir`, `.shop`, `.online`, `.store`, `.xyz`, `.design`)

---

## 📁 فایل‌های پروژه
* **`index.html`**: داشبورد تعاملی و ارائه گرافیکی ریسپانسیو (شامل فیلترها، جستجوی زنده و کارت‌های وضعیت با فونت وزیرمتن).
* **`bartan_domains_report.csv`**: خروجی جدول کامل برای اکسل و نرم‌افزارهای تحلیل داده.
* **`bartan_domains_report.json`**: ساختار کامل داده‌ها با تفکیک وضعیت و قیمت‌های ثبت و تمدید.
* **`check_domains.py`**: اسکریپت پایتون جهت اسکن خودکار پسوندها از طریق DNS DoH و ICANN RDAP.
* **`iranserver_all_tlds.json`**: دیتابیس تعرفه‌های رسمی ۴۳۹ پسوند استخراج شده از ایران‌سرور.

---

## 🚀 نحوه اجرا
برای اجرای مجدد یا بررسی یک کلیدواژه دیگر:
```bash
python3 check_domains.py bartan
```
